# Figma Stealer

Показывает, что в ваших файлах Figma сделано по дизайн-системе, а что мимо неё, и сразу ведёт
к слою, который нужно поправить. Цвета, токены, типографика, тексты, отступы, эффекты, картинки,
комментарии и компоненты — по любому числу файлов. Работает с любыми файлами и любой
дизайн-системой, на вашем компьютере, нужен только Python.

[English version](README.md)

![Цвета: сводка, рекомендации и все цвета в макетах](docs/screenshots/colors.png)

## Попробовать за минуту

Аккаунт Figma не нужен: демо собирает выдуманное приложение магазина с типичными проблемами
и открывает его в браузере.

```bash
python3 -m coloro demo
```

Нужен Python 3.9 или новее, тот, что есть в macOS, подходит. Больше ничего ставить не нужно.
Команда — `coloro`: так называется пакет внутри.

## Что показывает

Каждый раздел начинается со своей **сводки**: главные числа и как они изменились с прошлого
обновления, рекомендации по порядку пользы с кнопкой «показать эти места», файлы, где хуже всего,
и график «как менялось». Любое число открывает места за ним, со ссылками прямо на слой в Figma.

### Цвета

Все цвета, которые реально стоят в макетах, по тому, что с ними делать:

- *почти токен* — на глаз не отличить, заменить на токен;
- *другая прозрачность* — цвет токена с другой прозрачностью;
- *вне системы* — далеко от всех токенов: добавить в систему или заменить;
- *не привязан* — значение токена набрано вручную: привязать, на экране ничего не изменится.

Разница цветов считается по CIEDE2000 — так, как видит глаз. Сортировка по применениям, файлам,
светлоте и семейству, поиск по hex, токену и файлу. **Градиенты** — рецептами: вид и стопы
по порядку.

**Контраст.** Для каждого слоя известна его поверхность: заливка ближайшего фрейма или подложки
под ним, полупрозрачное смешано так, как видит глаз. Цвет текста проверяется против неё по
WCAG 2.2: не проходит, AA, AAA. Текст на картинке, градиенте или на краю подложки помечен
«проверить глазами»; у текста с обводкой учитывается обводка.

![Контраст текста против фона](docs/screenshots/contrast.png)

**Поверхности.** Все фоны в макетах; строка раскрывается в список того, что на этом фоне
применяется: цвета текста с контрастом и компоненты.

![Поверхности и что на них стоит](docs/screenshots/surfaces.png)

### Токены

Таблица как панель переменных в Figma: коллекции вкладками, группы по пути в имени, колонка на
каждую тему. «Привязано» считается по точным привязкам переменных в макетах, по ключу
переменной; «вручную» — то же значение без переменной. Отмечены неиспользуемые токены и токены,
которые меняются с темой.

![Токены по темам](docs/screenshots/tokens.png)

Справочник токенов — файл: выгрузка переменных Figma, W3C Design Tokens (включая стабильный
формат 2025.10), Tokens Studio или любой CSV. Без справочника система берётся из стилей и
переменных, найденных в самих файлах.

### Типографика и тексты

**Типографика** — тексты без стиля против системы стилей, выведенной из макетов: точно как стиль
(назначить его), почти стиль (на пиксель мимо), вне системы.

![Типографика](docs/screenshots/typography.png)

**Тексты** — все тексты макетов, одинаковый текст в разных местах — одна строка: повторы,
тексты в одном месте, одни и те же слова, написанные по-разному («Add to cart» и «Add to Cart»),
тексты без стиля.

![Все тексты](docs/screenshots/text.png)

### Отступы, скругления, обводки и эффекты

Числа против шкалы: шкала берётся из значений, привязанных к переменным, а если их нет —
из привычной сетки (отступы с шагом 4). Тени и размытия, набранные вручную, — против стилей
эффектов.

![Отступы против шкалы](docs/screenshots/spacing.png)

### Картинки

Одна строка на картинку по всем её местам: повторы и забытые заглушки.

### Комментарии

Обсуждения в файлах с экраном, к которому каждое приколото: открытые, без ответа, открытые
дольше 30 дней, закрытые. Сортировка по дате, по молчанию и по числу ответов, фильтр по человеку
и файлу, группировка по экранам. В сводке — типичное время до закрытия.

![Комментарии](docs/screenshots/comments.png)

### Компоненты

Где стоит каждый компонент, какие варианты, сколько инстансов переопределено, какие фреймы
похожи на отвязанные копии и на каких фонах стоит каждый компонент. Компонент, который почти
всегда на светлом, а в нескольких местах на тёмном, отмечается: там обычно нужен другой вариант.
По желанию — превью: Figma рисует каждый вариант, свойства (Size, State…) переключаются как
в Figma, с разметкой выбранного варианта для разработки.

![Компоненты](docs/screenshots/components.png)

### Поиск

Одна строка сверху: текст в любой форме слова и в любом порядке — по надписям, названиям слоёв
и фреймов, названиям компонентов (тогда находятся все их инстансы) и названиям страниц и файлов.
По желанию прощает опечатки, понимает слово, набранное в другой раскладке или транслитом, и
сверяет всё это со словами, которые действительно есть в макетах. Ширина и высота с допуском,
цвет с палитрой, пипеткой, прозрачностью и допуском. Части складываются: «Купить» + 56 × 56 +
розовый — именно такие кнопки. Фильтры по найденному: тип, компонент, свойства вариантов,
страница.

![Поиск](docs/screenshots/search.png)

### Отчёт

Один HTML-файл без внешних файлов: отправить, приложить, распечатать.

## Интерфейс

По три плавающих блока с каждой стороны. Слева — проекты (у каждого продукта свои файлы,
справочник токенов и история) и файлы (галочка включает файл, клик по названию оставляет только
его). Справа — типы контента и настройки с фильтрами выбранного типа. Каждая сторона
сворачивается в одну плавающую кнопку, которая продолжает показывать прогресс и ошибки; на узком
экране блоки открываются выпадающими. Тёмная и светлая темы; английский и русский языки
переключаются в настройках (шестерёнка).

![Интерфейс на русском](docs/screenshots/russian.png)

![Светлая тема](docs/screenshots/light.png)

Нужный вид открывается по ссылке, например `#/colors?view=contrast` или `#/search?q=checkout`.

## Работа со своими файлами

```bash
python3 -m coloro serve
```

В macOS можно просто дважды нажать `Figma Stealer.command`. Откроется браузер. Дальше:

1. **Настройки (шестерёнка)** — вставить персональный токен Figma (Figma → Settings → Security →
   Personal access tokens) с правом чтения содержимого файлов и комментариев, а чтобы
   добавлять папки целиком — ещё и папок (Folders: read). Там же можно загрузить справочник
   токенов проекта, если он есть.
2. **New project** и **Add files** слева — вставить ссылки на файлы Figma. Ссылка на папку
   (`https://www.figma.com/files/folder/…` или `…/files/team/…/folder/…`) добавляет все файлы
   папки; файлы, которые уже есть в проекте, пропускаются. Страницы можно ограничить словами
   в названиях.
3. **Update.** Первая загрузка большого файла занимает минуты, обновление без изменений —
   секунды: проверяется только версия файла и скачиваются только изменённые страницы.
   Комментарии обновляются при каждом обновлении.

Токен можно положить и в `~/.config/coloro/token` или в переменную окружения `FIGMA_TOKEN`.
Из терминала:

```bash
python3 -m coloro load "https://www.figma.com/design/…" --pages checkout
```

## Фильтры

При загрузке сохраняется всё — скрытые слои, архивные страницы, служебные секции — с метками.
Что считать, решают фильтры при просмотре; они общие для всех разделов, поэтому числа всегда
сходятся. По умолчанию считается то, что видно на экране:

| Фильтр | По умолчанию |
|---|---|
| Скрытые слои | не считаются |
| Архивные страницы (archive в названии) | не считаются |
| Слои внутри компонентов | считаются — они видны |
| Страницы по названию | все |
| Секции по названию | ничего не исключено |
| Дата появления слоя | за всё время |

Тексты без стиля, отступы, эффекты и безымянные фреймы считаются только у положенного на экран
вручную: внутри компонента их задаёт библиотека.

## Где лежат данные

Всё хранится на вашем компьютере в одном файле, `~/.coloro/coloro.sqlite` (демо —
`~/.coloro/demo.sqlite`). Никуда ничего не отправляется, кроме запросов к Figma. Сервер слушает
только `127.0.0.1` и не отвечает чужим страницам. Токен хранится доступным только вам и никогда
не отдаётся интерфейсу. Удаление файла удаляет его данные; чтобы удалить всё, удалите файл базы.

## Масштаб

Проверено на 32 рабочих файлах сразу, 4,3 млн слоёв:

| | |
|---|---|
| Загрузка всех | 20 минут, без сбоев |
| Обновление без изменений | 8 секунд |
| Общая картина | 4 с в первый раз, дальше мгновенно |
| Цвета | 1 с |
| Поиск по тексту и размеру | 0,6 с |
